# Глосарій предметної області

| Термін | Визначення |
| ------ | ---------- |
| Клієнт | Особа, чиї замовлення враховуються системою для обліку та прогнозування повторного відвідування кав'ярні. |
| Адміністратор | Користувач, який має доступ до адміністративних функцій системи, зокрема керування клієнтами, товарами та кав'ярнями. |
| Каса | Система кав'ярні, зі статусом оплати замовлення якої інтегрується система. |
| Замовлення | Зафіксована покупка клієнта в кав'ярні. |
| Завершене замовлення | Замовлення, для якого каса повідомила статус оплати як завершений. |
| Візит | Одне завершене замовлення клієнта в кав'ярні. |
| QR-код клієнта | QR-код, який використовується для ідентифікації клієнта. |
| Бонус | Облікова одиниця бонусної системи, пов'язана з клієнтом. |
| Баланс бонусів | Облік бонусів клієнта в системі. |
| Кав'ярня | Окремий заклад, у якому клієнти здійснюють замовлення. |
| Мережа кав'ярень | Сукупність кав'ярень, які обліковуються в системі як одна мережа. |
| Товар | Позиція асортименту кав'ярні, якою можна керувати в системі. |
| Статистика клієнта | Узагальнені дані про замовлення та візити окремого клієнта. |
| Статистика кав'ярні | Узагальнені дані про замовлення та візити в окремій кав'ярні. |
| Статистика мережі | Узагальнені дані про замовлення та візити в мережі кав'ярень. |
| ML-модель | Модель машинного навчання, що використовується для прогнозування ймовірності повернення клієнта. |
| ML-ознака | Характеристика даних про клієнта або його замовлення, яку може враховувати ML-модель під час прогнозування. |
| Прогноз повернення | Результат ML-моделі щодо ймовірності повторного відвідування клієнтом кав'ярні протягом періоду прогнозування. |
| Ймовірність повернення | Оцінка ML-моделі щодо ймовірності того, що клієнт повернеться до кав'ярні протягом періоду прогнозування. |
| Історія прогнозів | Збережені результати прогнозу повернення клієнта. |
| Повернення клієнта | Наявність хоча б одного нового завершеного замовлення клієнта в кав'ярні протягом наступних 30 днів. |
| Період прогнозування | Наступні 30 днів, протягом яких визначається, чи відбулося повернення клієнта. |

## Узгоджені значення

- **Візит** = одне завершене замовлення.
- **Повернення** = хоча б одне нове завершене замовлення протягом наступних 30 днів.
