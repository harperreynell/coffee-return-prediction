# Кодинговий агент

## Обраний агент

OpenAI Codex

## Клас інструменту

AI coding agent.

## Спосіб доступу

Агент використовується для безпосередньої роботи з файлами локального Git-репозиторію.

## Доступні операції

- аналіз структури репозиторію;
- читання файлів;
- створення та редагування файлів;
- виконання команд у робочому середовищі;
- аналіз змін;
- підготовка змін до коміту.

## Роль у лабораторній роботі

Кодинговий агент буде використано для аналізу структури проєкту та внесення контрольованої зміни до одного з файлів репозиторію.
